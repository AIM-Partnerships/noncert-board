# Non-Cert Hiring Board

AIM Industry Partnerships job board, refreshed every Monday. Not connected to Optimus.

Three lanes, kept separate:
- **In-field (non-cert):** aviation jobs AIM students and grads can be hired into without an A&P.
- **Survival jobs:** part-time and flexible work within about 25 miles of each campus.
- **Transferable skills:** entry-level technician jobs outside aircraft maintenance within about 50 miles of each campus.

Every job links to a live posting checked on the pull date. The board is `index.html`.
